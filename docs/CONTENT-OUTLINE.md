# Population Outline

Use this checklist before replacing the placeholders in `data/story.json`.

1. **Company overview** — approved origin story, mission, and what Byrock does.
2. **Unmet need** — audience, problem definition, burden, and careful boundaries around claims.
3. **Science** — hypothesis, mechanism, plain-language explanation, and known uncertainty.
4. **Research evidence** — approved results, limitations, dates, and one citation per claim.
5. **Regulatory path** — jurisdiction, status, intended next steps, and prohibited implications.
6. **Trial design** — population, endpoints, safeguards, and what is not yet known.
7. **Team** — approved biographies, roles, and conflicts disclosures where required.
8. **Pipeline** — programs, stage, indication, and what can be publicly discussed.

For each node provide: final title, short summary, citations, media brief, alt text, tags, and permitted next branches. Keep review status and approver outside the public JSON if a CMS is introduced.
